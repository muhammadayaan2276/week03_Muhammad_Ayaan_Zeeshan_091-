# Week 3 -- Assignment and Lab Practice

This repository contains my **Week 3 OOP assignment and lab practice**,
focusing on geometrical and mathematical objects using Java and
object-oriented programming concepts.

## Assignment Tasks

### 1. Triangle Using Point

Designed and practiced the `Triangle` class using the `Point` class and
three Point objects.

### 2. Point Operations

Practiced: - Point addition - Point subtraction - Copy constructor -
`toString()` - Creating and using Point objects

Example:

``` text
Point 1: (2.0, 3.0)
Point 2: (4.0, 5.0)
Addition: (6.0, 8.0)
Subtraction: (2.0, 2.0)
Copied Point: (2.0, 3.0)
```

### 3. Stack and Heap Visualization

Visualized **Stack and Heap for Point addition** using Python Tutor.

The visualization demonstrates: - Point object creation - Object
references - Stack and Heap memory - Point addition - Creation of the
resulting Point object

Visualization file:

`Stack_Heap_Point_Addition_Visualization.png`

Tool used: Python Tutor

### 4. Complex Number

Practiced the `ComplexNumber` class with real and imaginary parts,
including basic operations such as addition and subtraction.

### 5. Rational Number

Practiced the `RationalNumber` class using numerator and denominator and
applying object-oriented programming concepts.

## How to Run

Open the required demo folder in a Java-supported IDE such as VS Code.

Compile the Java files:

``` bash
javac *.java
```

Run the main class:

``` bash
java Main
```
